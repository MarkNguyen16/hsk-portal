⚙️ Cấu Hình Kết Nối Cloud Database (Firebase / RestDB)

Nếu để trống, hệ thống sẽ lưu trữ và quản lý trong bộ nhớ trình duyệt của máy này.
💡 Hướng dẫn tạo Firebase Realtime DB miễn phí (30 giây):
  1. Truy cập console.firebase.google.com, đăng nhập bằng Gmail cá nhân.
  2. Bấm Add project (Tạo dự án mới đặt tên bất kỳ, ví dụ: HSK3-Results).
  3. Vào menu trái chọn Build > Realtime Database > Bấm Create Database.
  4. Ở mục Rules, đặt ".read": true, ".write": true để cho phép gửi điểm.
  5. Sao chép đường link URL (dạng https://...firebaseio.com) và dán vào ô bên trên.
